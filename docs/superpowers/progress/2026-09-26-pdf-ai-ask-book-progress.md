- Task 2：同源搜索、普通问答、流式问答增加独立 PDF 分支。服务端验证 UID、授权路径、扫描指纹、PDF 开关和会话所有权；不接受客户端提交上下文/引用。取消从索引阶段起传播到上游；无效模型引用降级为“依据不足”，不保存未核验答案。
- Task 3：沿用 AI 问书面板，增加 PDF 范围选择和对外发送提示。工具栏与单页文本菜单可进入，来源页点击后跳转且面板保持打开；保存来源绑定指纹，旧 PDF 变化时展示过期状态并禁止跳转。EPUB 问书保持原请求与界面逻辑。

## 经验与后续

- PDF 页是稳定的证据单位，不能套用 EPUB 章节解析和客户端上下文；引用可点击之前必须由服务端确认索引行、页码和文件版本。
- 仅在 AI 完成后清洗非法引用会让未经核验的结论短暂显示；PDF UI 因此先缓存流式文本、核验完再展示，失败则只显示安全提示。
- PDF 选文需要同时验证“入口能点击”和“选文确实进入证据”；只测工具栏显示会漏掉操作分发层的旧拦截。
- 后续如果加入 OCR、语义检索或章节推断，应另立契约、预算和隐私评审，不能悄悄放宽本计划的范围。
