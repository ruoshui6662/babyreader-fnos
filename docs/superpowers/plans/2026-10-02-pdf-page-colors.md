# PDF 页面颜色跟随主题（2026-10-02）

## 背景

PDF 页由 PDF.js 画在 canvas 上，阅读主题（浅色/护眼/深色）此前只改外框，页面始终白纸黑字。

调研：WPS PDF 提供“背景 → 夜间模式/护眼模式”与自定义背景色；Okular 有反色、反转明度（保留色相）、改纸张颜色；SumatraPDF 整页反色，照片会变成底片（用户长期反馈）；PDF.js 自带 `pageColors`（Firefox 高对比度）按亮度把整页映射到前景/背景两色，需要重新渲染，照片变成单色调。

## 方案（已实施）

- **只改显示，不重绘**：在已渲染的 canvas 上用 CSS 调色，切换主题瞬间生效。
  - 深色：`invert(1) hue-rotate(180deg) contrast(0.76)`——明暗反转、色相保留（蓝色标题仍是蓝色），纸色 `#1f1f1f`、文字 `#e0e0e0`。
  - 护眼：canvas 以 `multiply` 叠在米黄纸色 `#f3e8cf` 上——纸变米黄，黑字仍黑。
  - 浅色：原样。
- **深色下图片保持原色**：从 PDF.js 操作列表（`getOperatorList`）跟踪变换矩阵，找到每张图片（含表单 XObject 内的图片、重复平铺图片）的位置；把这些区域的像素从页面 canvas（CSS filter 不改变像素）复制到叠放在上面的小 canvas，略调暗（`brightness(0.86)`）。最大的一张图片占页面一半以上时视为扫描页，整页照常反色。曾尝试用 `backdrop-filter` 再反转一次抵消，但 `hue-rotate` 会截断高饱和颜色（红、蓝发灰），故改为像素复制。
- **划线与选区**：深色下文字层与划线、搜索高亮层改用 `screen` 混合，选区颜色改为深色版本，否则在深色纸上看不见。
- **设置**：PDF 专属的“PDF 页面颜色：跟随主题 / 原样”（`pdfPageColors: 'theme' | 'original'`，服务端白名单），给不适合调色的设计类文档使用。
- 代码：`app/ui/reader/pdf-colors.js`（新）、`pdf.js`（暴露 PDF.js `OPS`、提交帧时附带 `page`、关闭时清理缓存）、`styles.css`、设置面板。

## 测试

- 新夹具 `e2e-mixed-images.pdf`：第 1 页文字 + 直接绘制的彩色图片 + 表单 XObject 内的图片；第 2 页整页图片（扫描页）。
- `e2e/pdf-page-colors.spec.js`：深色滤镜、两张图片的位置与像素颜色（红色区域仍为红）、扫描页不保留、选区混合方式；护眼的混合与纸色；浅色与“原样”无滤镜、设置保存与刷新后保持；非 PDF 不显示该设置。
- 服务端：`pdfPageColors` 白名单与按用户隔离。

## 待真机确认

iOS Safari / 飞牛 App 内置浏览器上 canvas 的 `filter`、`mix-blend-mode` 效果与性能；大量图片的 PDF 在深色下的首屏耗时（每页多一次操作列表读取，结果按页缓存）。

## 后续修正（2026-10-02）

用户反馈深色下文字对比度低、不够白、不清晰。原因：线性映射 `contrast(0.76)` 把黑字变成 `#e0e0e0`，细笔画中文字形的抗锯齿边缘是中间灰，线性映射后仍偏暗，看起来发灰、发虚。改为 SVG 滤镜：反色 → `hueRotate 180` → 伽马（amplitude 0.83、exponent 0.7、offset 0.12，sRGB 空间），纸色 `#1f1f1f`、文字 `#f2f2f2`，抗锯齿边缘被提亮，笔画更实。
