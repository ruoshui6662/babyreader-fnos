# 移动端阅读适配规划（调研与规划，未执行）

日期：2026-10-01 状态：待用户确认

## 1. 现状问题（手机 375×812 实测 + 代码核对）

### 1.1 划线在手机上不可用（最严重）

代码位置：`app/ui/reader/highlights.js` `setupDomHighlightInteraction`、`app/ui/reader/selection-menu.js` `setupSelectionMenu`。

| 原因 | 后果 |
| --- | --- |
| 选区菜单只在 `touchend` / `pointerup` / `mouseup` 后检查选区；正文区没有监听 `selectionchange` | **Android Chrome 长按选字只产生 `touchstart → selectstart → selectionchange`，没有 `touchend`**（触摸被系统接管），菜单根本不弹出 |
| 拖动系统选区手柄调整范围只产生 `selectionchange` | iOS 上首次能弹出，一调整范围菜单就消失且不再出现 |
| `document` 上任何 `pointerdown` 都会先关闭菜单 | 手指去拖选区手柄时菜单被关掉 |
| `resize` 与任意 `scroll` 都会关闭菜单 | 手机长按时地址栏收起、可视区变化，会把刚弹出的菜单关掉 |
| 自定义菜单放在选区**上方** | 与系统“复制/分享”浮条位置重叠；iOS 的系统菜单无法用网页屏蔽 |
| 菜单 7 个文字按钮 + 4 个颜色，手机上折成两行 | 拥挤，易误触 |

### 1.2 阅读页按钮与操作方式

- 右下角常驻一个漂浮的“⋯”按钮负责呼出工具栏，不是手机阅读器的习惯（主流做法：轻点屏幕中间呼出/隐藏）。
- 顶栏常驻（返回、书名、主题），下方还有一段约 80px 的空白条；沉浸感差、浪费屏幕。
- 底部工具栏一排 7 个小按钮（书架、目录、书签、搜索、笔记、划线、设置）：“书架”与返回重复；“划线”需要先选中文字才有意义；**没有 AI 问书入口**；没有阅读进度条和上一章/下一章。
- 分页模式只有左右滑动翻页，没有“点左右边缘翻页”；滚动模式下任意轻点都会切换工具栏。
- 返回手势/返回键不会关闭打开的面板，而是直接离开阅读页。
- 中英文混排两端对齐时，中文字间距被拉得很开（如“效 ， 同 时 提 供”）。

### 1.3 面板

- 设置：底部面板把全部选项铺成一个长列表（含下拉选择框“阅读模式”），没有拖拽把手、不能下滑关闭。
- 目录：底部面板，未高亮当前章节、不会滚动到当前位置。
- AI 问书：只能从选区菜单进入；头部挤了 5 个按钮，副标题被挤换行；输入框没有随键盘上移的处理。

### 1.4 书库

- 顶部“新建分类 / 导入 / 重新扫描 / 整理”四个按钮横排，是桌面做法；书籍没有长按菜单（重命名、移动分类只能进“整理”）。

### 1.5 移动 Web 基础

- 视口没有 `viewport-fit=cover`；没有 Web App Manifest、`apple-mobile-web-app-capable`、`theme-color`，无法“添加到主屏幕”全屏使用。
- 阅读区未统一防止下拉刷新、双击缩放延迟（`overscroll-behavior`、`touch-action: manipulation`）。

## 3. 目标设计（手机，宽度 < 768px）

### 3.1 阅读页结构

```
┌──────────────────────────────┐   呼出时：
│ ‹  书名（单行省略）   🔍 🔖 ⋯ │   顶栏：返回 · 书名 · 搜索 · 书签开关 · 更多（书籍信息/导出/主题）
│                              │
│          正  文              │   隐藏时：正文全屏，只留极淡的页码/进度（可在设置关闭）
│                              │
│ ‹ 上一章  ━━━━●━━━━  下一章 › │   底栏第 1 行：章节跳转 + 进度滑块（拖动时气泡显示章名与百分比）
│  目录   笔记   AI   夜间   Aa │   底栏第 2 行：5 个图标 + 文字
└──────────────────────────────┘
```

- 轻点规则（分页模式）：左 1/3 上一页，右 1/3 下一页，中间呼出/隐藏上下栏；左右滑动翻页。滚动模式：轻点任意处呼出/隐藏，上下滑动阅读。
- 去掉右下角“⋯”浮钮、顶栏常驻与下方空白条；上下栏呼出 4 秒无操作自动收起（保留现有逻辑）。
- 主题切换移入底栏“夜间”和顶栏“更多”。
- 安全区：上下栏和面板用 `env(safe-area-inset-*)` 留出刘海与底部横条。

### 3.2 划线与选区菜单

- 触发：同时监听 `selectionchange`（防抖约 250ms）与 `touchend/pointerup`；选区非空且在正文内就显示菜单。
- 不再因“按下”“页面滚动”“窗口尺寸变化”关闭菜单：改为跟随选区重新定位；只有选区变空、点了菜单项、点了正文空白处才关闭。
- 位置：手机上放在选区**下方**（避开系统复制/分享浮条），下方空间不足时放上方；横向不超出屏幕。
- 样式：深色单行气泡，图标 + 文字：**划线 · 写想法 · 复制 · 问 AI · 搜索**。点“划线”立即用上次的颜色和样式划好，并在气泡上方展开“颜色 + 样式”条供修改（与微信读书一致），不再一次铺出 11 个按钮。
- 点已有划线：弹出同样的气泡：颜色/样式、写想法、复制、删除。
- 选字时暂停滑动翻页，避免拖手柄时误翻页。
- PDF 文字层使用同一套逻辑。

### 3.3 面板（统一成“底部抽屉”）

- 统一组件：顶部拖拽把手；下滑关闭；点遮罩关闭；**手机返回手势/返回键先关闭面板**（打开面板时写入一条 history 记录）；高度分半屏/近全屏两档。
- 设置（Aa）半屏：字号（A− 滑块 A+）、背景色块（含夜间）、字体（横向滚动卡片）、翻页方式（分页/滚动 分段控件）；“更多设置”进入二级：行距、页边距、首行缩进、两端对齐、显示页码等。
- 目录：近全屏抽屉，顶部标签“目录 / 书签 / 笔记”；当前章高亮并自动滚到可见位置；每章右侧显示页码或进度。
- AI 问书：近全屏抽屉；头部只保留标题与关闭，“导读 / 会话 / 新对话 / 设置”收进头部的“⋯”菜单；输入框贴底并随软键盘上移（`visualViewport`）；选中文字时从选区菜单直接进入。

### 3.4 书库

- 右上角“⋯”菜单收纳：导入、重新扫描、新建分类、整理；搜索框保留。
- 长按书籍弹出菜单：打开、重命名、移动到分类、在“整理”中排序；“整理”模式在手机上底部出现操作条。
- 封面列数：≥360px 三列，更窄两列（现状已接近）。

### 3.5 移动 Web 基础

- `viewport-fit=cover`；新增 Web App Manifest（名称、图标、`display: standalone`、主题色）与 iOS 对应的 meta，支持“添加到主屏幕”后全屏阅读。
- 阅读区：`overscroll-behavior: none`（防下拉刷新/回弹露底）、`touch-action: manipulation`（去掉双击缩放延迟）、`100dvh` 统一高度。
- 排版：手机端两端对齐时改用 `text-justify: inter-character` 并允许长英文单词断行，消除中文字距被拉开的问题；“两端对齐”作为可关闭选项。

## 4. 分阶段计划（每阶段：实现 → 单元/DOM 测试 → Playwright 手机视口与触摸模拟 → 全量回归 → 提交）

| M3 书库 | “⋯”菜单收纳操作、长按书籍菜单、整理模式底部操作条 | 手机上导入/扫描/新建分类/重命名/移动分类均可完成 |

真机说明：开发机只能模拟手机视口和触摸事件，系统选区手柄、软键盘、刘海屏等需要在真机上按 M4 清单确认。

## 5. 需要确认的决定

1. 手机默认翻页方式：**左右分页**（像微信读书，推荐）还是保持现在的上下滚动？两种都会保留，只是默认值不同。
2. 底栏 5 个入口：目录、笔记、AI、夜间、Aa（推荐）；或换成 目录、书签、AI、Aa 等组合。
3. 是否做“添加到主屏幕”（PWA）全屏模式（推荐做，成本低，体验接近 App）。
4. 分页模式点左右边缘翻页（推荐）还是只用滑动翻页。

## 6. 用户决定（看过草图后，2026-10-01）

1. 阅读页工具栏：**A 两行底栏**（第 1 行 上一章 / 进度条 / 下一章；第 2 行 目录、笔记、AI、夜间、设置；顶栏 返回、书名、搜索、书签、更多）。
2. 选字菜单：**方案一 气泡**（选区下方深色单行气泡；点“划线”立即划好并展开颜色与样式）。
3. 手机默认阅读方式：**左右翻页**（点左右两侧或左右滑动翻页，中间呼出菜单）；上下滚动保留为可选项。
4. **支持“添加到主屏幕”**全屏使用。

执行顺序：M0 → M1 → M2 → M3 → M4，每阶段完成并回归通过后自动进入下一阶段。

## 7. 执行记录

### M0 划线修复（完成）

- 选区菜单改为在 `selectionchange` 稳定 250ms 后弹出（鼠标拖选未松开时不弹，桌面行为不变），Android 长按选字不再依赖 `touchend`。
- 手指按下、页面滚动、窗口尺寸变化不再关闭菜单，而是跟随选区重新定位；选区清空才关闭。鼠标在菜单外按下仍会关闭（桌面习惯）。
- 手机上菜单在选区下方（留出系统选区手柄空间，底部不够时放上方），单行“划线 · 写想法 · 复制 · 问 AI · 搜索”；“划线”沿用上次选择的样式与颜色。
- 新增划线气泡：手机上划线后、或点已有划线（EPUB/MOBI/TXT）时弹出，可改颜色与样式（立即保存）、写想法、复制、问 AI、删除；样式选择会被记住。PDF 划线画在画布上，仍从笔记列表修改。
- 关闭选区或气泡的那一下轻点，不再同时呼出工具栏。
- 测试：新增 `e2e/mobile-selection.spec.js`（无 `touchend` 也能弹出菜单、调整选区菜单不消失、划线与气泡改色改样式、再次点击划线、删除）；更新选区菜单动作数与手机 PDF 断言。

### M1 阅读页交互（完成）

- 去掉右下角浮动 ⋯：轻点页面中部呼出/隐藏顶栏与底栏，两者都浮在正文上，正文不再因工具栏出现而重排；栏打开时再点页面任意处只收起。
- 点按区：左右翻页时左 1/3 上一页、右 1/3 下一页、中间呼出工具；上下滚动、纯文本、PDF 点任意处呼出工具。滑动翻页后的那次点击不会再翻一页。
- 顶栏（手机）：返回 · 书名 · 搜索 · 书签（显示当前页是否已加书签）· ⋯（书签列表 / 导出标记与想法 / AI 问书）。
- 底栏两行：第一行“上一章 · 进度条 · 下一章”（PDF 为上一页/下一页），拖动进度条时气泡显示目标章节与百分比，松手跳转；第二行“目录 · 笔记 · AI · 夜间/日间 · 设置”。
- 工具收起时底部安静地显示当前章节与百分比。
- 手机单独保存阅读方式 `mobileReadingMode`（默认左右翻页），设置里显示为“左右翻页 / 上下滚动”；不再改动桌面端的阅读方式，反之亦然。服务端设置白名单已加入该字段。
- 返回手势/返回键：打开的面板（目录/笔记/设置/搜索/AI 及其子页/划线编辑/⋯ 菜单）各占一条历史记录，返回先关最上层面板；没有面板时返回书架。
- 刘海与底部横条：`viewport-fit=cover` + `env(safe-area-inset-*)`。
- 手机打开书时不再自动展开目录（会盖住整页正文）。
- 顺带修复：复制在剪贴板 API 失败后走旧路径时会清掉读者当时的选区，现在会还原。
- 测试：DOM 测试更新工具栏结构、手机阅读方式默认值与桌面隔离，新增点按区测试；E2E 更新书签/搜索/返回书架入口，新增返回手势与点按翻页 + 进度条跳章测试。
- 说明：原计划保留“上下栏 4 秒无操作自动收起”，实施时去掉了——拖进度条、找按钮时栏会突然消失；改为翻页、滚动或轻点正文时收起（与微信读书一致）。

### M2 面板（完成）

- 统一底部抽屉：目录/书签/笔记、设置、搜索、AI 顶部都有拖拽把手；在把手或标题栏上下拉超过约四分之一高度关闭，短拉回弹；返回手势同样先关面板（M1）。
- 设置先开半屏：字号、背景、字体（横向滑动一行）、翻页方式（“左右翻页 / 上下滚动”分段控件）；“更多设置”展开划线颜色和排版等全部选项，下次打开恢复为半屏。手机上不显示“默认展开目录”（手机不会自动展开目录）。
- 目录打开时标出当前章节并滚到可见位置（桌面同样生效）。
- AI 问书在手机上近全屏，头部只留标题、⋯、关闭；“本书导读 / 会话列表 / 新对话 / AI 设置”收进 ⋯；面板底边跟随软键盘（`visualViewport`），输入框不被遮挡。
- 测试：新增 `e2e/mobile-panels.spec.js`（375/390/430 宽度下设置/目录/AI 无横向溢出、AI 贴底满宽；翻页方式切换与更多设置；拖拽关闭与回弹；目录当前章；AI ⋯ 菜单与返回逐层关闭）。

### M3 书库（完成）

### 真机验收清单（需在设备上确认）

开发机只能模拟视口和触摸事件，以下几项请在真机上确认：

1. iOS Safari、Android Chrome、飞牛 App 内置浏览器：长按选字后菜单出现在选区下方、不与系统复制条重叠；拖动选区手柄时菜单不消失。
2. 轻点中间呼出/收起上下栏；左右 1/3 翻页；左右滑动翻页；拖动进度条跳章。
3. 系统返回手势/返回键：先关面板，再回书架；在书架上不会误退出。
4. 刘海屏与底部横条：顶栏、底栏、目录/设置/AI 面板不被遮挡。
5. AI 问书输入时软键盘弹出，输入框不被遮挡。
6. 书库：长按书籍弹出操作单（而非系统菜单）；整理模式长按拖动排序。
7. 添加到主屏幕：图标正确，从主屏幕打开为全屏（无地址栏），经网关登录后能正常进入。
8. PDF 双指缩放、单指滚动、选字划线。
