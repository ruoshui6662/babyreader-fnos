# 阅读体验精修计划（2026-10-04）

参照 Legado 的阅读页设计，从第一性原理出发。阅读的本质是持续投入注意力：屏幕上只有书，需要知道的信息一眼可见，控制离手指一步之遥，默认就好用，细节层层展开。

**范围**

- 不做：朗读、离线下载、自动翻页（用户已确认）。
- 要做：
  - 修复安卓 App 选中文字时弹出系统菜单的问题；
  - 重做设置的视觉；
  - 页眉页脚信息栏；
  - 九宫格点击区；
  - 阅读样式预设；
  - 选中菜单扩展。

**发布方式**：每个阶段单独提交、可以单独打包。版本号依次递增 patch，安卓客户端有改动时也递增它的版本号。

## 现状问题（2026-10-04 截图核对）

“更多设置”的完整设置页：

1. **卡片套卡片**：面板本身有边框，里面的分组又是一张带边框的卡片，分组里的控件再各自带底色，一共三层。
2. **对齐不统一**：
   - “液态玻璃”的开关在左、文字在右，“左右滑动翻页”却是另一种排法；
   - 说明文字、“查看点击区域”链接和“收起”按钮夹在列表中间。
3. **控件语言混杂**：
   - 划线颜色用下拉框，其余选项用分段控件；
   - 字体卡片横向排列，超出屏幕被截断。
4. **颜色不统一**：开关是蓝色，选中项是主题橙色，链接又是另一种颜色。
5. **层级重复**：顶部有标题、关闭按钮，还有拖动条；“外观 / 阅读 / 划线 / 排版”四个小标题字号很小、灰度很浅，起不到引导作用。

安卓 App（ColorOS 16）：

- 长按选中文字时，系统会在文字上方弹出“复制 / 剪切 / 全选 / 分享 / 翻译”的浮动条，和枕书自己的选中菜单叠在一起。

## R0 修复选中文字时的系统菜单（安卓客户端）

**原因**：WebView 选中文字时会启动系统的 ActionMode（浮动工具条），ColorOS 还会往里面追加翻译、搜索等项。

**方案**：

- 客户端用自定义的 WebView 子类，重写 `startActionMode(callback, type)`，包一层回调。
  - 在 `onCreateActionMode` 和 `onPrepareActionMode` 里，先执行原有逻辑，再清空菜单。
  - 菜单为空时系统不会显示浮动条，但选区和拖动手柄仍然保留，枕书自己的选中菜单照常出现。
  - 不调用 `finish()`，否则 WebView 会清掉选区。
- `setTextClassifier(TextClassifier.NO_OP)`（API 27+）：关闭“智能选择”自动扩选和链接识别，避免 ColorOS 自行扩大选区。
- 网页端不需要改，枕书的选中菜单已经有“复制”。
- 客户端升级到 0.2.2。

**验收**：在模拟器上长按选中文字，只出现枕书的菜单；能拖动手柄调整选区；“复制”可用。ColorOS 上的效果由用户在真机确认。

## R1 设置的视觉重做：纸本质感

**方向**：像一本书的版权页或目录页，而不是一张表单。

- 不用边框，靠留白和细分隔线分组。
- 标题有书卷气。
- 只用一种强调色，随主题变化。
- 控件少而统一。

**设计规范（手机）**

- **整体**：
  - “更多设置”改为从底部升起、几乎全屏的页面，顶部只有拖动条和一个“完成”。
  - 去掉标题栏和关闭按钮的重复：拖动条加“完成”就够了。
- **分组标题**：衬线字体（思源宋体），15px，正文色，前面加一个很淡的序号（壹 / 贰 / 叁 / 肆）。分组之间留 28px，不用卡片和边框。
- **行**：
  - 高 52px，左边是名称，右边是控件或当前值加“›”，行与行之间用 0.5px 细线分隔（左侧与文字对齐）。
  - 开关一律放在右侧；说明文字作为该行的小字副标题，不单独成段。
- **控件只保留三种**：
  - 分段控件：选项不超过 4 个时，横排，整行宽；
  - 列表选择：选项多或需要预览时，点击进入下一层，例如字体、划线颜色；
  - 滑块：沿用阅读面板里那种胶囊滑块，数值显示在滑块上。
- **颜色**：强调色统一取主题色（浅色和深色是系统蓝，护眼是赭石色），开关、选中项、链接全部使用它。不再出现蓝橙混用。
- **字体**：列表里每一项都用该字体本身显示名称，右侧打勾；不再用横向卡片。
- **划线颜色**：四个色点横排，不用下拉框。
- **去掉**：“收起”按钮（完整设置页不需要折叠）；把“恢复默认”移到页面底部，作为一行低调的文字按钮。

**阅读面板（进度 / 主题 / 设置）同步精修**

- 面板顶部加一条很淡的拖动条，暗示可以下滑关闭。
- 面板内的选中态、开关颜色统一取主题强调色。
- 面板与工具栏之间不画分隔线，二者是同一块纸面。
- 桌面端：保留卡片式布局（大屏上它是合适的），只统一强调色和分组标题字体。

**验收**：在 390px 宽度下截图，与改版前逐屏对比；浅色、护眼、深色三种主题都检查一遍。

## R2 页眉页脚信息栏

参照 Legado 的 `TipConfigDialog`，把时间、进度这类状态信息画在页面里，不依赖系统状态栏。

- **位置**：页眉、页脚各有左、中、右三个位置。
- **可选项目**：时间、电量、书名、章节名、章节内页码（“3/12”）、全书进度（%）、无。
- **预设**：
  - 默认：页眉左是章节名；页脚左是时间，右是进度。
  - 极简：只有页脚右侧显示进度。
  - 全信息：页眉左是书名、右是章节名；页脚左是时间和电量，中间是章节页码，右是进度。
  - 自定义：分别指定每个位置显示什么。
- **电量**：安卓 App 通过 `ZhenshuNative.battery()` 读取（BatteryManager，广播通知变化）；浏览器里不显示电量这一项。
- **与现有元素的关系**：取代现在的页脚和沉浸模式下的时钟；页眉高度沿用 `--reading-top` 那条安全区。
- **设置入口**：“设置”面板 › 更多设置 › 页眉页脚。
- **适用范围**：EPUB、TXT、Markdown 和 PDF。PDF 只显示时间、电量、页码和进度。

## R3 九宫格点击区，以及翻页器按键

- **九宫格**：
  - 把屏幕分成 3×3 九格，每格可以指定一个动作：上一页、下一页、菜单、目录、书签、无。
  - 预设：
    - 左右分区：等同现在的默认；
    - 点击下一页：等同现在的单手模式；
    - 上下分区：上排上一页，下排下一页，中间菜单；
    - 自定义。
  - 编辑界面就是一张屏幕缩略图：点一格就弹出可选动作，当前设置直接写在格子里。
  - 点击区说明层（首次进入时的引导）按当前设置画出九格。
- **翻页器按键（安卓 App）**：
  - 把蓝牙翻页器常用的键映射为上一页、下一页：翻页键（PageUp / PageDown）、方向键、空格，以及部分翻页器发送的音量键。
  - 设置里加一个开关“翻页器按键”，默认开。
- **兼容**：服务端把原有的 `tapToTurn` 设置迁移为九宫格预设，不丢失用户已有的选择。

## R4 阅读样式预设

- **样式**：
  - 现有的浅色、护眼、深色三种成为内置样式；
  - 新增“自定义”：背景色、文字色，以及可选纸纹（细麻、宣纸、无），最多保存 4 套。
- **日夜联动**：
  - 指定一套“日间样式”和一套“夜间样式”，可以选择“跟随系统”自动切换（`prefers-color-scheme`）；
  - 主题面板里的月亮按钮就是在两套之间切换。
- **亮度（安卓 App）**：
  - 主题面板加亮度滑块，加一个“跟随系统”开关；
  - 通过 `ZhenshuNative.setBrightness()` 调整窗口亮度，只在阅读时生效，回到书库时恢复。
- **同步**：样式存在服务端的用户设置里，多设备一致；亮度属于每台设备自己，存在本机。

## R5 选中菜单扩展、字重、简繁转换

- **选中菜单**：
  - 在现有的“划线 / 想法 / 复制 / 卡片 / 问 AI”之外，加“搜索本书”（直接用选中的文字做全书搜索）；
  - 安卓 App 里再加“更多”：调用系统的文本处理（`ACTION_PROCESS_TEXT`），可以交给词典、翻译等已安装的应用处理选中的文字。这样 R0 去掉系统浮动条后，原有能力也不会丢失。
- **字重**：排版里加“字重”：细、常规、中、粗。只对支持可变字重或带多个字重的字体生效，其他字体置灰并说明。
- **简繁转换**：排版里加“简繁”：原文、简体、繁体，仅改变显示，不修改文件。
  - 用本地的字表转换（OpenCC 的简繁字表），不依赖网络；
  - 全书搜索仍按原文进行。
