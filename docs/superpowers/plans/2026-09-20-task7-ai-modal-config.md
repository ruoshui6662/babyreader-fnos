# Task7 增量：独立 AI 弹窗与服务配置

## 目标

将现有 AI 抽屉面板拆为独立模态弹窗，并增加可实际保存和使用的 OpenAI-compatible URL、API Key、模型名配置。

## 实施步骤

- [x] 服务端增加按用户隔离的 AI 配置存储、原子写入和脱敏响应。
- [x] `GET/PUT /api/ai/config` 与 AI 状态/提问接口打通。
- [x] AI 入口从 Drawer 解耦，改为独立遮罩和弹窗，Esc/关闭按钮/背景点击均可关闭。
- [x] 按参考样式增加回答卡片、来源、推荐问题和底部输入区。
- [x] 配置视图支持 URL、模型名、API Key、保留 Key、清除 Key。
- [x] 增加 Node、DOM、Chromium 配置和弹窗回归测试。
- [ ] 再次执行全量测试和 FPK 打包。

## 稳定性边界

- 不改动书本索引、标记、想法和导出数据结构。
- 不把 API Key 放进用户阅读状态、localStorage、浏览器缓存或响应 JSON。
- 环境变量仍可作为默认配置；用户配置只覆盖当前用户的 URL、模型和 Key。
