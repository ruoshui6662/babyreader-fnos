# 液态玻璃主题（可选）· 计划

演示：`docs/demos/liquid-glass/index.html`（分支 `demo/liquid-glass`）。

## 1. 用户决定（2026-10-03）

- 做成**可选主题**：设置里打开，默认关闭；关闭时界面与现在完全一致。
- 背景光两种，用户选择：
  - **取自封面**（默认、推荐）：从“继续阅读”那本书的封面提取主色，换书时约 0.8 秒渐变过渡。
  - **统一色**：非常淡的 iOS 蓝（系统蓝 #007AFF 的色相 211；浅色约 `hsl(211 100% 94%)`，深色约 `hsl(211 50% 19%)`）。

## 2. 范围

只给“浮在内容之上”的控件层上玻璃；内容层（封面、正文、笔记与统计卡片的文字）保持实心。

| 位置 | 内容 |
| --- | --- |
| 书库 / 阅读统计 / 笔记 | 悬浮侧边栏；顶部“搜索 + 操作”胶囊工具条；分类标签条；下拉与“⋯”菜单；卡片面板；选择长图浮条；手机悬浮底部标签栏 |
| 阅读页 | 浮动工具条、上一页 / 下一页胶囊、选区菜单、批注气泡 |

## 3. 做法

- **玻璃材质**：`backdrop-filter: blur() saturate()`，加一层很薄的白（浅色）或黑（深色），边缘有高光描边，顶部有一层柔光。
- **浓玻璃**：带小字的控件（标签栏、菜单）用更不透明的玻璃，保证文字在彩色封面上也看得清。
- **透镜折射**：只在 Chromium 内核浏览器（Chrome、Edge）开启，用 SVG 位移滤镜做轻微弯折；Safari 退回普通毛玻璃。
- **背景光（取自封面）**：
  1. 把封面画到 40×60 的画布上；
  2. 读出像素，相近颜色分桶，跳过偏灰、偏白、偏黑的像素；
  3. 取最多、且彼此明显不同的三种颜色，不足时用同一色相、降低饱和度补足；
  4. 按主题调整明度；
  5. 写入 `--amb-1/2/3` 三个颜色变量（用 `@property` 注册为颜色，才能渐变）；
  6. 结果按书 id 缓存到 localStorage；没有封面的书用自动生成封面的主色。
- **可访问性**：系统开启“减少透明度”时改为不透明的玻璃；开启“减少动态效果”时取消背景光渐变。
- **按钮**：沿用 `zs-btn` 三种角色，只在 `html[data-glass="on"]` 下调整外观，不新增按钮样式；`tests/ui-buttons.test.js` 继续有效。

## 4. 设置

阅读设置 → 外观，新增：

- 液态玻璃：开 / 关（默认关）。
- 背景光：取自封面 / 统一色（淡蓝），只在开启液态玻璃时显示。

两项都保存在服务端用户设置里（与主题、字体一起），多设备同步。

## 6. 执行记录

### G1（完成）

- 设置：服务端用户设置新增 `liquidGlass`（默认 false）与 `glassAmbient`（`cover` / `uniform`），随主题一起同步。
- `core/glass.js`：根属性 `data-glass` / `data-glass-ambient` / `data-glass-lens`；封面取色（40×60 画布、分桶、跳过灰白黑、按主题调整明度）与按书缓存；生成封面要等放到页面上后才读得到颜色；淡蓝背景光；书库顶栏“外观”菜单（主题、液态玻璃、背景光）。阅读设置“外观”组有同样两项。
- 验收：关闭时与 main 逐像素对比，阅读页完全一致，书库只差新加的“外观”按钮。

### G2（完成）

- 电脑：悬浮圆角侧边栏、玻璃顶栏、页头“搜索 + 操作”胶囊、分类标签胶囊；菜单、手机“⋯”菜单、卡片面板、选择长图浮条为浓玻璃。
- 手机：悬浮胶囊标签栏，书页滚到它下面；整理栏和选择长图浮条上移到标签栏之上。
- 性能（书库 100 本书，连续滚动 200 帧，统计超过 20ms 的帧，与关闭时交替测量）：
  - 最初：关闭约 3 帧，打开约 49～89 帧。
  - 原因有三：滚动区域透明（每帧都要和背景混合）、侧边栏的透镜折射、随内容滚动的胶囊实时模糊。
  - 调整：
    - 滚动区域保持不透明，背景光只画在页面顶部 900px 的一块上；
    - 电脑端侧边栏、顶栏、胶囊下面只有静止平滑的背景光，所以不做实时模糊，只用半透明、边缘高光和阴影；
    - 透镜只用于弹出菜单；
    - 手机标签栏下面有内容滚过，保留实时模糊。
  - 结果：电脑端打开 4 帧、关闭 15 帧（同一轮交替测量，差别在误差内）；手机端打开、关闭都是 0 帧。
- 测试：`e2e/liquid-glass.spec.js` 新增 2 项（电脑悬浮侧边栏与胶囊、关闭复原；手机悬浮标签栏、内容滚到其下、选择浮条在其上）。截图在 `docs/screenshots/glass/`。

### G3（完成）

- 电脑：右侧浮动工具条与双页翻页胶囊改为玻璃（浓玻璃底色、边缘高光、阴影），不做实时模糊（正文会从下面滚过）。
- 选区菜单与批注气泡：在任何主题下都是深色玻璃（72% 不透明，白字在白纸上的对比度约 5.9:1），带模糊；它们只是短暂出现，不影响滚动。
- 手机阅读：顶栏为浓玻璃；底部工具条变成离屏幕边缘 12px 的悬浮圆角卡片。
- 正文、纸张、PDF 页面均不变；“减少透明度”下改为不透明。
- 测试：`e2e/liquid-glass.spec.js` 新增 2 项（电脑工具条与选区菜单、关闭复原且纸张不变；手机悬浮工具卡片）。测试结束后恢复玻璃设置为关闭，公共的 `resetReaderSettings` 也会重置玻璃设置，避免影响其他测试。截图 `docs/screenshots/glass/g3-*`。
