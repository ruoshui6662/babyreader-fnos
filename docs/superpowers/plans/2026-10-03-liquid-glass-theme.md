# 液态玻璃主题（可选）· 计划

演示：`docs/demos/liquid-glass/index.html`（分支 `demo/liquid-glass`）。

## 1. 用户决定（2026-10-03）

- 做成**可选主题**：设置里打开，默认关闭；关闭时界面与现在完全一致。
- 背景光两种，用户选择：
  - **取自封面**（默认、推荐）：从“继续阅读”那本书的封面提取主色，换书时约 0.8 秒渐变过渡。
  - **统一色**：非常淡的 iOS 蓝（系统蓝 #007AFF 的色相 211；浅色约 `hsl(211 100% 94%)`，深色约 `hsl(211 50% 19%)`）。

## 2. 范围

只给“浮在内容之上”的控件层上玻璃；内容层（封面、正文、笔记与统计卡片的文字）保持实心。

| 位置 | 内容 |
| --- | --- |
| 书库 / 阅读统计 / 笔记 | 悬浮侧边栏；顶部“搜索 + 操作”胶囊工具条；分类标签条；下拉与“⋯”菜单；卡片面板；选择长图浮条；手机悬浮底部标签栏 |
| 阅读页 | 浮动工具条、上一页 / 下一页胶囊、选区菜单、批注气泡 |

## 3. 做法

- **玻璃材质**：`backdrop-filter: blur() saturate()`，加一层很薄的白（浅色）或黑（深色），边缘有高光描边，顶部有一层柔光。
- **浓玻璃**：带小字的控件（标签栏、菜单）用更不透明的玻璃，保证文字在彩色封面上也看得清。
- **透镜折射**：只在 Chromium 内核浏览器（Chrome、Edge）开启，用 SVG 位移滤镜做轻微弯折；Safari 退回普通毛玻璃。
- **背景光（取自封面）**：
  1. 把封面画到 40×60 的画布上；
  2. 读出像素，相近颜色分桶，跳过偏灰、偏白、偏黑的像素；
  3. 取最多、且彼此明显不同的三种颜色，不足时用同一色相、降低饱和度补足；
  4. 按主题调整明度；
  5. 写入 `--amb-1/2/3` 三个颜色变量（用 `@property` 注册为颜色，才能渐变）；
  6. 结果按书 id 缓存到 localStorage；没有封面的书用自动生成封面的主色。
- **可访问性**：系统开启“减少透明度”时改为不透明的玻璃；开启“减少动态效果”时取消背景光渐变。
- **按钮**：沿用 `zs-btn` 三种角色，只在 `html[data-glass="on"]` 下调整外观，不新增按钮样式；`tests/ui-buttons.test.js` 继续有效。

## 4. 设置

阅读设置 → 外观，新增：

- 液态玻璃：开 / 关（默认关）。
- 背景光：取自封面 / 统一色（淡蓝），只在开启液态玻璃时显示。

两项都保存在服务端用户设置里（与主题、字体一起），多设备同步。
