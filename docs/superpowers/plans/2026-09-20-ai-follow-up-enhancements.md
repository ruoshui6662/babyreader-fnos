# AI 后续增强开发计划

本计划登记多轮对话后的增强需求。AI 阶段 1 的安全稳定部分已在 `2026-09-20-ai-phase1-security-stability.md` 执行完成；以下未标记部分仍暂不执行。

## 一、配置和网络安全

- [x] 增加“测试连接”按钮，在不发送书本内容的情况下验证 URL、Key 和模型；
- [x] 校验服务 URL 协议、域名、端口和重定向策略；
- [x] 防止自定义 URL 访问本机、内网管理端口和非授权地址；
- [x] 对上游响应体大小、重定向次数和错误内容做限制；
- [x] 展示可操作的配置错误，而不是等待首次提问才发现配置无效。

## 二、服务端书本内容可信边界

- 服务端根据 `bookId` 重新读取书本或读取服务端索引；
- 校验客户端提交的章节路径、文本片段和内容摘要；
- 防止客户端伪造其他书本上下文；
- 保留当前前端检索作为低延迟模式，逐步增加服务端验证模式。

## 三、检索质量

- [x] 评估当前关键词检索的召回率和误召回率；
- [x] 增加章节标题和小节标题权重；
- 增加 SQLite FTS 或其他本地全文检索；
- 评估 Embeddings 和向量索引；
- 形成关键词、全文检索、向量检索的混合排序；
- 对长书建立可复用、可失效的索引缓存。

## 四、会话产品能力

- 会话持久化和重新打开恢复（规划见 `2026-09-20-ai-conversation-persistence.md`，暂不执行）；
- 会话导出 Markdown；
- 删除会话和清空单轮消息；
- 重新生成回答；
- 失败重试；
- 书本级问答历史；
- Token、请求次数和估算费用显示。

## 五、无障碍与真机验收

- AI 弹窗焦点陷阱和 Tab 循环；
- 屏幕阅读器读取用户问题、回答增量和来源章节；
- reduced-motion 动画策略；
- fnOS x86_64/ARM64 安装测试；
- 移动输入法、剪贴板、WebView 网络和权限测试；
- 移动端长按选区菜单与问 AI 联动。
