#### 阶段 2 的实现约束

- SQLite 文件由服务端按需创建，用户无需手动安装、配置或维护；
- 中文内容先转换为可检索的二元词片，再交给 SQLite FTS5，避免默认 tokenizer 将整段连续中文视为单一 token；
- FTS 端点只负责候选召回，原有服务端书本上下文校验和 AI 请求协议保持不变；
- FTS 不可用、索引构建失败或搜索请求失败时，前端继续使用现有内存关键词索引，不影响阅读和问答主流程；
- FPK 不携带 SQLite 数据库和用户书籍，索引只在设备运行时生成。

## 稳定性约束

- 阶段 1 不改服务端 AI 请求协议和 API Key 流程；
- 索引构建失败时回退到现有前端关键词检索；
- 不把整本书发送给模型；
- 发送给模型的片段数量和总长度必须有硬上限；
- 不把用户笔记、其他书本或网络内容混入默认书本上下文。
