# 移动端连续滚动阅读改造规格

## 目标

在 Android、iPhone、iPad/iPadOS 的浏览器中，让连续滚动模式以正文为中心，避免固定工具栏遮挡内容；PC 模式继续保持现有布局和交互。

## 交互规则

- 移动端连续滚动默认不显示固定底部工具栏。
- 上一章和下一章属于章节边界控件，保留在正文流中：上一章位于章节顶部，下一章位于章节底部。
- 连续滚动模式隐藏上一页、下一页；分页模式继续显示分页控制。
- 点击阅读区域中部切换移动工具栏，工具栏最多一行，显示目录、划线、设置、返回书架四个动作。
- 工具栏打开时尊重底部安全区；滚动阅读或打开面板后自动收起。
- 所有移动动作通过现有 `data-reader-action` 事件代理执行，禁止为移动兼容按钮继续增加独立动作监听。

## 设备边界

- Android、iPhone、iPod、iPad UA 判定为移动阅读界面。
- iPad 桌面模式使用 `MacIntel + maxTouchPoints > 1` 判定。
- 普通 PC 和 Windows 触控桌面保持桌面界面。
- 窗口尺寸、方向和触控能力变化时重新计算界面画像。

## 非目标

- 不改变桌面端翻页按钮位置、书架布局、EPUB 解析和章节加载策略。
- 不一次性加载整本 EPUB。
- 不改变阅读设置、划线数据格式和阅读进度格式。

## 验收标准

1. 移动端连续滚动正文默认没有两行固定按钮，正文底部不被工具栏覆盖。
2. 移动端连续滚动只在章节顶部/底部显示上一章/下一章，分页按钮不出现。
3. 移动端点击正文中部可以打开和关闭一行工具栏，目录、划线、设置和书架功能仍可用。
4. iPad 桌面模式进入移动界面，普通 PC 小窗口不进入移动界面。
5. PC 桌面端现有连续滚动、分页和工具栏布局保持不变。
6. npm 单元测试、结构检查和 Chromium 回归测试通过。
