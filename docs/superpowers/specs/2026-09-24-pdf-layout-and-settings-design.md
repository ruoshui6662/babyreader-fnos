# PDF 阅读布局与设置对齐设计

日期：2026-09-24。状态：已确认，待实施。前置文档：`2026-09-23-pdf-reader-design.md`。

## 目标与现状

用户希望 PDF 与 EPUB 共享一致的阅读外壳、工具视觉和设置入口，并能切换双页阅读；翻页、缩放应在长文档、窄屏与搜索跳转后保持可预测。首版 PDF 设计仅承诺纵向连续页流。现有 `settingReadingMode` 修改的是 EPUB `state.readingMode`，PDF 控制器不读取该值，因此在 PDF 中选择“双页分页”没有效果。

第一阶段的翻页/缩放控制改进已在当前未提交工作区实现：控件分组、实际倍率显示、适宽随视口变化、放大后横向可达、缩放保持目标页和 PDF 快捷键。下述设计仅覆盖后续 PDF 布局与格式化设置；不将第一阶段未经 NAS 安装验收的结果视为实机完成。

## 产品行为

- PDF 阅读模式提供“连续”“单页”“双页”三个互斥选项，默认“连续”，与现有 PDF 行为兼容。设置面板为 PDF 展示独立选项，不复用 EPUB 的 `readingMode` 状态或分页算法。
- “单页”仍以原有纵向页面流为基础，但启用按页滚动吸附；上一页/下一页每次移动一页。不隐藏其他页，以免破坏懒渲染、搜索与目录定位。
- “双页”在可用阅读宽度足够时并排显示。第 1 页单独居中，此后 2–3、4–5 配对；末尾单页居中。上一页/下一页移动到相邻页组。页码输入、目录与搜索结果仍可定位到页组中的任一确切页面。
- 可用宽度低于 900 CSS px 时，双页偏好保留，但实际显示退化为单页；恢复宽屏后自动回到双页。退化不覆写持久化设置，也不清除页定位。
- 缩放百分比表示 PDF.js 的实际渲染倍率。手动倍率保持不变；“适宽”按当前布局的单页宽度或双页总宽度（含页间距）计算。超过容器的手动放大允许阅读区内横向滚动，不能裁掉画布或文本层。
- PDF 设置保留主题和目录相关通用选项；字体、行距、段落和划线颜色等无法作用于 PDF 页面的选项不在 PDF 上展示。EPUB/TXT 的设置项及保存值保持原样。

## 状态、页面定位与实现边界

- 新增独立的用户级 `pdfLayoutMode: 'continuous' | 'single' | 'double'`。旧设置缺失或非法时回退为 `continuous`；服务端只接受白名单值。沿用现有用户隔离与 JSON 原子写入，不增加数据库或书籍文件写入。
- PDF `pageIndex` 继续是 0-based 的唯一进度、搜索与目录定位。双页只是视图编组，不更改 locator/API/FTS 格式。直接跳到右页时，显示所属页组，但当前页码与进度仍记录目标右页；用户手动翻页后记录新页组的首个实际页面。
- PDF 控制器拥有模式切换与布局计算；通用设置面板只读写 PDF 专属偏好。PDF 页节点、文本层和搜索标记继续由原控制器维护；优先通过 CSS 网格/吸附改变布局，不复制页面、Canvas 或 PDF.js Viewer。
- 模式或宽度变化时先记录当前 `pageIndex`，完成布局和必要的倍率调整后恢复同一页/页组。滚动监听不得在切换过程把临时可见页误写成阅读进度。快速换书和关闭沿用现有 generation 取消机制。
- 懒渲染仍只处理可见页及有限邻页；双页不得为全书预渲染、无界抓取页面尺寸或突破已有 Canvas 像素/边长/页数预算。混合尺寸 PDF 的适宽计算只加载当前页组的尺寸，缓存有界；无法读取某页时显示受控错误，不拖垮另一页或整个阅读器。

## 安全与兼容边界

- 不改书库授权路径、Gateway 身份校验、Range 内容端点、本地 FTS 索引、PDF.js 本地资产/CSP、EPUB CFI/分页/划线、TXT 阅读行为。
- 不新增 OCR、PDF 批注、AI、远程资源加载或文件写回。PDF 功能继续受现有 PDF 开关控制，禁用后既有书库和阅读流程不变。
- 只改 PDF 控制器、PDF 专属样式、设置显隐/状态与对应用户设置白名单；任何共享模块改动须附 EPUB/TXT 回归测试。

## 验收

1. 单元测试覆盖页组映射：1、2、3、4、444 页；首页、末页、右页直达、窄屏退化及非法设置回退。
2. 浏览器测试覆盖三模式切换、上一组/下一组、页码输入、搜索命中右页、目录跳转、刷新恢复、改宽度和暗色模式；搜索面板不能被跳转关闭。
3. 放大、适宽、文本层和命中矩形在单/双页均对齐，无裁切；资源预算不高于现有上限，快速换书后旧渲染不得回写新书。
4. EPUB/TXT 阅读设置、翻页、书签/标注、全文搜索与书库流程全量回归；NAS 实机安装前不宣称最终验收通过。

## 分阶段实施

1. 冻结 PDF 页定位、设置与资源预算的测试基线，先写失败用例。
2. 实现 PDF 布局模式和页组翻页，保持精确 `pageIndex`。
3. 接入 PDF 专属设置与用户级白名单持久化，按内容格式显示适用选项。
4. 补齐双页适宽、窄屏退化、搜索/目录/进度回归，运行完整浏览器测试和 fnOS 实机验收。
