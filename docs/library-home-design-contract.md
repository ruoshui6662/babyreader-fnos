# 书库首页视觉与扩展契约

本文记录书库首页的设计约束，以及后续功能接入时不得破坏的边界。最初依据 `zhenshu_apple_hig_demo_v6_stability_rule.html`；2026-09-30 按 Apple Human Interface Guidelines 完成第二轮改版（见文末“2026-09-30 HIG 改版”）。它只适用于书库页，不授权重排 EPUB/PDF 阅读器或改变服务端 API。

## 目标与实现范围

- 书籍封面与书名是主视觉；弱化无必要的外框、描边和阴影。
- 继续阅读、分类、书籍网格采用稳定的层级和间距，不引入空白占位卡片。
- 页面最大内容宽度为 1280px；桌面左右留白至少 40px，平板约 24px，手机约 16px。
- 书封统一为 `1:1.45` 的同尺寸画框，桌面每本约 130px 宽（1280px 书架每行 8 本；v1.3.2 的 100px 真机反馈过小）；真实封面用 `object-fit: cover` 居中填满（比例特殊的封面会裁掉少量边缘，换取书架整齐），3px 圆角，用极轻的 `box-shadow`；“继续阅读”卡片中的 48×70 封面同样处理。
- “新建分类”点击后，输入框以胶囊形式内联在分类标签行末尾（新分类将出现的位置）；Esc 或“取消”关闭并把焦点还给“新建分类”；名称为空时本地提示，不发请求。
- 没有封面的书使用生成封面：按书籍 ID（FNV-1a）稳定取 8 种色调之一，排版书名、作者和格式标签；PDF 渲染出首页后替换。
- 书名最多两行（13px），作者与进度一行（12px/11px）；同一行书卡的封面顶端对齐。
- 分类仍使用现有横向导航；继续阅读仍使用已有阅读进度数据；扫描、搜索、分类和拖拽仍由现有逻辑负责。
- 书库首页标题与阅读正文标题样式隔离：继续阅读标题不继承正文的桃色下划线。
- 工具区中，搜索框与操作按钮在桌面同一行（HIG 填充式搜索栏）；操作顺序固定为“新建分类 → 重新扫描 → 整理/完成”；管理员且开启导入时为“新建分类 → 导入 → 重新扫描 → 整理/完成”，分类详情页中“导入”位于“添加书籍”之后、“整理”之前。平板（< 920px）标题与工具栏上下排列，手机（< 680px）搜索框独占一行。
- 按钮层级：普通操作为灰色填充按钮；“新建分类/添加书籍”为强调色浅底；只有“完成”是实心强调色（iOS Done 惯例）。“返回书库”为强调色纯文字加装饰性箭头，箭头不得进入可访问名称。
- 分类使用胶囊标签并显示数量，选中态为反色填充；拖动手柄只在“整理”模式显示（键盘聚焦时展开）。分类标签位于“继续阅读”之上，因为它同时限定“继续阅读”和书架。
- 首页顶栏提供外观（深/浅色）切换，与阅读器共用 `toggleTheme`。

## 响应式与视觉 Token

列数不再固定，而是按封面最小宽度自动排满（`repeat(auto-fill, minmax(最小宽度, 1fr))`），列宽略微拉伸，使两侧与工具栏对齐：

| 视口宽度 | 封面最小宽度 | 间距（行/列） | 实测 |
| --- | ---: | --- | --- |
| ≥ 920px | 128px | 36 / 32px | 1560 宽：每行 8 本，封面 132×191 |
| 680–919px | 112px | 30 / 24px | 平板 |
| < 680px | 88px | 24 / 16px | 375 宽：每行 3 本，封面 104×150（微信读书 App 同为 3 列） |

书库使用局部 `--library-*` token，取值对应 Apple 语义色：浅色画布 `#FBFBFD`、卡片 `#FFFFFF`、填充 `rgba(118,118,128,.12)`、主文字 `#1D1D1F`、强调色 `#007AFF`；深色（默认主题，body 无主题类，选择器为 `body.is-library:not(.theme-light):not(.theme-sepia)`）画布 `#1C1C1E`、卡片 `#2C2C2E`、强调色 `#0A84FF`。米黄阅读主题回到书库时使用浅色书库调色板。不要为达到视觉一致而覆盖全局阅读主题、全局强调色或 `:root` token。

控件使用 10px 圆角（分类标签为胶囊），无描边；封面 hover 上浮 2px 并略加深阴影，按下缩放到 0.975；“继续阅读”为紧凑卡片（最宽 420px、约 94px 高、14px 圆角），含 48×70 封面、进度条和“继续”胶囊。颜色、状态和焦点 ring 必须满足所选主题的对比度，并保留 `:focus-visible`、触屏最小 44px 目标和 `prefers-reduced-motion` 行为。

## 稳定扩展锚点

渲染器在现有节点上添加 `data-library-slot`，供新增首页模块定位；这些锚点只是 DOM 集成点，不是后端 API：

| `data-library-slot` | 节点 | 用途 |
| --- | --- | --- |
| `header` | `.library-header` | 页面标题与现有操作区 |
| `header-actions` | `.library-header-actions` | 搜索、扫描等现有操作的同级扩展 |
| `categories` | `.library-category-navigation` | 组织模式下的分类导航 |
| `recent-reading` | `.library-recent-reading` | 有有效阅读进度时才出现的继续阅读模块 |
| `book-grid` | `.library-grid` | 书籍列表锚点，也是可选模块的默认插入边界 |

接入新的首页模块时：

1. 只在对应书库容器内查找锚点，不依赖全局 ID、节点顺序以外的脆弱层级或 CSS `nth-child`。
2. 模块应为可选；没有可展示数据时不创建节点、不占高度。
3. 默认在书籍网格之前插入，不移动/重建现有书卡，不改变 DOM 中书籍顺序。
4. 若新模块需要持久化、扫描、权限或远程服务，先单独定义 API、授权、错误回退和测试，不可把它们塞进样式层或借用不相关 API。
5. 创建 DOM 使用 `textContent` 与显式事件监听；对用户/书籍元数据不拼接未净化 HTML。
6. 保留现有 class 和所有旧 DOM ID。扩展属性不得被用于书籍身份、分类归属或授权判断。

## 安全与稳定边界

本轮允许：书库作用域 CSS、上述无行为副作用的 `data-library-slot` 属性、对应的回归测试与本文档。

本轮禁止：更改书籍/分类排序、拖拽激活、搜索匹配、扫描触发/结果、阅读进度读写、分类 API、文件授权、PDF 封面请求、阅读器 DOM ID、EPUB/PDF 阅读区域和任何服务端数据结构。

验收应覆盖 flat 与 organization 两种首页渲染、分类和最近阅读的有无、筛选后的空结果，以及桌面/平板/手机断点；对拖拽、点击打开和扫描至少做不回归检查。所有既有工作区改动属于用户/当前工作，不在本任务中清理、暂存、提交或重置。

## 2026-09-30 书籍导入（MOBI/导入计划 Task 5）

- “导入”按钮与其他工具按钮同为灰色填充样式，只在 `features.bookImport` 为 true（管理员且开关开启）时出现；没有该功能时工具栏与之前完全一致。
- 整个书架是拖放目标：拖入文件时显示强调色虚线框和“松开以导入到书库”（伪元素，不进入可访问名称）；页面其他位置的文件拖放会被阻止，避免浏览器离开书库去打开文件。
- 导入队列面板挂在 `body` 上（书库重渲染时不会丢失）：桌面为右下角浮动卡片，手机为底部面板并避开底部安全区；逐个文件显示进度条（`role="progressbar"`）、结果和“取消/打开”，汇总通过 `aria-live` 播报；有进行中的上传时“完成”按钮不可用。
- 在分类详情页导入的书自动放入该分类（沿用带 revision 的归类 API）；书库只在仍停留在书库页时刷新，不会打断阅读。

## 2026-09-30 阅读界面 v2（参考微信读书网页版）

依据 v1.3.0 的真机反馈：顶栏阴影重、纸张阴影大、不够沉浸，以及浅色和护眼米黄配色颠倒。新样式集中写在 `styles.css` 末尾的 “Reading surface v2” 区块中，可以整体审查或回退。

| 主题 | 纸张 | 舞台（纸张外） | 右侧按钮 |
| --- | --- | --- | --- |
| 浅色 | `#FFFFFF` | `#F2F3F5` | 白色圆形 |
| 护眼米黄 | `#F6F0E1`，文字 `#3A3226` | `#E9E0CC` | `#F8F3E7` 圆形 |
| 深色（默认） | `#1C1C1E` | `#141416` | `#26262A` 圆形 |

- **顶栏**（书库和阅读页）：无阴影、无分隔线，底色为舞台色加 86% 透明度和模糊，与背景融为一体。PDF 工具栏同样处理。
- **纸张**：无边框，圆角 12px。浅色和米黄只用两层极淡阴影（贴边的 1px 加 20px 的柔光），深色用 1px 亮边来区分，不用投影。
- **连续滚动、双页分页、PDF 页面**使用同一套纸张表现；PDF 页面放在舞台色上，不再白纸叠白底。
- **桌面右侧工具栏**：取消外层胶囊，改为 44px 的独立圆形按钮，间距 12px，底色同纸张，阴影极轻。展开或当前状态用强调色浅底加细描边。手机端的底部工具栏保持原样。
- **主题修复**：以前护眼米黄的纸张是纯白，浅色的浮层却带着暖色（`#FCF8F1`），两者看起来颠倒。现在浅色完全是中性色，米黄是真正的暖色纸。E2E 用例 `浅色 is white paper… 护眼米黄 is warm paper` 专门守护这一点。书库仍然使用自己的中性配色。

### 双页阅读区放大（v1.3.1 真机反馈）

- 用户反馈双页的阅读区域比微信读书网页版略小。纸张总宽度保持不变，仍然是 `min(0.9 × 窗口宽, 窗口宽 − 128)`，上限 1344px，这样右侧圆形工具栏永远不会被压住。空间从纸张内部挤出来：
  - 页边距设置映射的系数从 1.75 改为 1.4，默认内边距从 70px 变为 56px，上限 84px；
  - 栏间距从 98px 改为 84px；
  - 纸张外侧上下留白从 56 / 40px 改为 40 / 24px；
  - 纸张内部上下边距从 64 / 56px 改为 56 / 60px。
- 实测 1460×900 的窗口：每栏宽度从 538px 增加到 559px，每页约多一行字。
- 翻页按钮改为 32px 高的无边框浅色小按钮，放在纸张底部内边距里。以前 40px 高的按钮会压住最后一行字约 8px，现在与文字保留 14px 的间距。
