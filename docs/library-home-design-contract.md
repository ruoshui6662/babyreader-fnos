# 书库首页视觉与扩展契约

本文记录 `babyreader_apple_hig_demo_v6_stability_rule.html` 对书库首页的设计约束，以及后续功能接入时不得破坏的边界。它只适用于书库页，不授权重排 EPUB/PDF 阅读器或改变服务端 API。

## 目标与实现范围

- 书籍封面与书名是主视觉；弱化无必要的外框、描边和阴影。
- 继续阅读、分类、书籍网格采用稳定的层级和间距，不引入空白占位卡片。
- 页面最大内容宽度为 1280px；桌面左右留白至少 40px，平板约 24px，手机约 16px。
- 书封统一采用 `3:4.2` 比例和 `object-fit: contain`，不裁切原封面。
- 书名、作者各单行省略；文字区固定高度，使网格各行保持基线对齐。
- 分类仍使用现有横向导航；继续阅读仍使用已有阅读进度数据；扫描、搜索、分类和拖拽仍由现有逻辑负责。
- 书库首页标题与阅读正文标题样式隔离：继续阅读标题不继承正文的桃色下划线。
- 根书库工具区中，搜索框单独占一行；操作顺序固定为“新建分类 → 重新扫描 → 整理/完成”。窄屏优先保持操作按钮同一行，搜索框按可用宽度收缩。

## 响应式与视觉 Token

| 视口宽度 | 网格列数 | 说明 |
| --- | ---: | --- |
| ≥ 1100px | 5 | 桌面宽屏 |
| 920–1099px | 4 | 窄桌面/横屏平板 |
| 680–919px | 3 | 平板 |
| < 680px | 2 | 手机；继续保持双列，避免极窄时突然变成单列 |

浅色书库使用局部 token：画布 `#F5F6F8`、主文字 `#17181B`、次级文字 `#767D89`、分隔线 `rgba(20,24,32,.075)`、强调色 `#3478F6`。深色模式定义各自的局部值。不要为达到视觉一致而覆盖全局阅读主题、全局强调色或 `:root` token。

控件使用 10–13px 小圆角、短而轻的阴影；封面 hover 位移不超过 1px。颜色、状态和焦点 ring 必须满足所选主题的对比度，并保留 `:focus-visible`、触屏最小 44px 目标和 `prefers-reduced-motion` 行为。

## 稳定扩展锚点

渲染器在现有节点上添加 `data-library-slot`，供新增首页模块定位；这些锚点只是 DOM 集成点，不是后端 API：

| `data-library-slot` | 节点 | 用途 |
| --- | --- | --- |
| `header` | `.library-header` | 页面标题与现有操作区 |
| `header-actions` | `.library-header-actions` | 搜索、扫描等现有操作的同级扩展 |
| `categories` | `.library-category-navigation` | 组织模式下的分类导航 |
| `recent-reading` | `.library-recent-reading` | 有有效阅读进度时才出现的继续阅读模块 |
| `book-grid` | `.library-grid` | 书籍列表锚点，也是可选模块的默认插入边界 |

接入新的首页模块时：

1. 只在对应书库容器内查找锚点，不依赖全局 ID、节点顺序以外的脆弱层级或 CSS `nth-child`。
2. 模块应为可选；没有可展示数据时不创建节点、不占高度。
3. 默认在书籍网格之前插入，不移动/重建现有书卡，不改变 DOM 中书籍顺序。
4. 若新模块需要持久化、扫描、权限或远程服务，先单独定义 API、授权、错误回退和测试，不可把它们塞进样式层或借用不相关 API。
5. 创建 DOM 使用 `textContent` 与显式事件监听；对用户/书籍元数据不拼接未净化 HTML。
6. 保留现有 class 和所有旧 DOM ID。扩展属性不得被用于书籍身份、分类归属或授权判断。

## 安全与稳定边界

本轮允许：书库作用域 CSS、上述无行为副作用的 `data-library-slot` 属性、对应的回归测试与本文档。

本轮禁止：更改书籍/分类排序、拖拽激活、搜索匹配、扫描触发/结果、阅读进度读写、分类 API、文件授权、PDF 封面请求、阅读器 DOM ID、EPUB/PDF 阅读区域和任何服务端数据结构。

验收应覆盖 flat 与 organization 两种首页渲染、分类和最近阅读的有无、筛选后的空结果，以及桌面/平板/手机断点；对拖拽、点击打开和扫描至少做不回归检查。所有既有工作区改动属于用户/当前工作，不在本任务中清理、暂存、提交或重置。
